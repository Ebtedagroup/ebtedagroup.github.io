# ebtedagroup.github.io
ابتدا گروپ — از ابتدای کار در کنارتان هستیم | موشن‌گرافیک، انیمیشن هوش مصنوعی و ارتقای سایت

## ساختار

- `index.html`: صفحه‌ی فارسی؛ `en.html`: صفحه‌ی انگلیسی. CSS و JS داخل خود هر فایل است (بدون فریم‌ورک و بدون build).
- `portfolio.js`: فهرست نمونه‌کارها برای هر دو صفحه. راهنمای فیلدها بالای همان فایل است. تا خالی است، بخش نمونه‌کارها نمایش داده نمی‌شود.
- فرم تماس با Formspree کار می‌کند (`action` فرم در هر دو صفحه).
- گوگل آنالیتیکس: شناسه‌ی Measurement را در متغیر `GA_ID` بالای هر دو صفحه بگذارید. تا خالی است، چیزی ارسال نمی‌شود.
- `favicon.png`، `favicon.ico`، `logo.png` و `og.jpg` (تصویر اشتراک در شبکه‌های اجتماعی، ۱۲۰۰×۶۳۰).
